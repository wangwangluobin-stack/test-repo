# AI 数据分析助手

一个本地运行的 CSV 分析助手：清洗数据、自动探索、比较清洗前后的质量评分、
生成图文报告，并通过规则解析回答自然语言问题。无需大模型 API、API Key 或网络服务。

## 快速开始

需要 Python 3.9+。依赖沿用 pandas、numpy、matplotlib 和 pytest，没有新增第三方库。

```bash
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
# Windows cmd: .venv\Scripts\activate.bat

python -m pip install -r requirements.txt
python src/make_sample.py

# 清洗、生成报告，然后进入交互式问答
python src/agent.py --input data/raw/sample.csv
```

问答默认基于**清洗后数据**；加 `--raw` 可询问原始数据，报告仍比较清洗前后。
保留原有批处理入口及参数：

```bash
python src/main.py --input data/raw/sample.csv
python src/agent.py --input data/raw/sample.csv --fill mean --no-outliers

# 非交互模式，多个问题共享上下文
python src/agent.py --input data/raw/sample.csv --question "平均年龄" --question "那中位数呢"
```

默认生成 `outputs/clean.csv`、`outputs/report.md` 和 `outputs/figures/` 下的三张图，
可通过 `--outdir` 更改目录。报告顶部展示质量总分和四个维度的清洗前后对比，
随后是自动发现、数值分布、类别频次、强相关特征对，以及原有数据概览、清洗日志和图表。
数据与输出目录中的生成文件不入库。没有适用数据时，对应图表可能不生成。

## 多轮问答

可直接使用 CSV 列名；示例数据还支持年龄 → `age`、收入 → `income`、
城市 → `city`、性别 → `gender`、得分 → `score` 等中文别名。

| 问法类别 | 示例 |
|---|---|
| 概览 | 数据概览 / 有哪些列 |
| 行数 | 有多少行 |
| 列数 | 有多少列 |
| 缺失值 | 缺失值统计 / 年龄有多少空值 |
| 重复行 | 重复多少行 |
| 均值 | 平均年龄 / mean age |
| 中位数 | 收入的中位数 |
| 总和 | 收入总和 |
| 最小值 | 最小年龄 |
| 最大值 | 最高收入 |
| 标准差 | 收入标准差 |
| 不同值数量 | 城市有几种不同值 |
| 频次 | 城市频次 |
| 相关性 | 年龄和收入的相关性 / 有哪些强相关特征 |
| 排序前 N 行 | 收入最高的前5行 / 年龄最低的前3行 |
| 条件筛选 | 年龄大于30 / 城市等于"北京" |
| 分组统计 | 按城市分组计算收入平均值 / 按城市分组有多少人 |

示例会话：

```text
你> 平均年龄
你> 那中位数呢
你> 那收入呢
你> 年龄大于30
你> 平均收入
你> 城市等于"北京"
你> 有多少行
你> 发现
你> history
你> 重置筛选
你> exit
```

追问可沿用上一轮列名或统计方法；筛选会持续生效并可以逐轮叠加，
`重置筛选` 清空筛选和列上下文。`发现` 分析当前筛选范围，`history` 显示最近 50 轮成功问答，
`help` 查看帮助，`exit`、Ctrl-D 或 Ctrl-C 退出。上下文仅保存在当前会话内。

解析器支持固定问法，不理解任意语言表达；含糊或不支持的问题会给出错误，不执行 Python 代码。
每次筛选支持一个条件，可用 `>`、`>=`、`<`、`<=`、`==`、`!=` 或中文比较词；
文本只支持相等/不等，含空格的值请加引号。数值筛选要求数值列。
支持“年龄大于30的平均收入”等单条件统计；复杂条件请逐轮筛选后提问。
前 N 行最多 100 行，频次最多显示 20 项，分组最多显示前 100 组；
摘要会说明截断范围。数值统计忽略 NA 与正负无穷，标准差采用样本标准差。
唯一值数量不计 NA，频次包含 NA，行重复按整行相等判断。

## 自动探索分析

`analyzer.analyze(df)` 返回 `overview`、`numeric`、`categorical`、`correlations` 和结构化 `findings`。

- **数值列**：均值、中位数、范围、样本标准差、偏度、IQR 异常值；有限观测至少 8 个时，
  按偏度阈值 ±0.5 判断左偏、右偏或近似对称，另识别常量列。该判断不是正态性检验。
- **类别列**：包括布尔和非数值类型，输出不同值数量、缺失数、前 10 项频次与占全部行的比例。
- **强相关特征对**：Pearson `|r| ≥ 0.7`、至少 3 对成对有效观测，跳过常量列；
  不重复输出镜像特征对。相关不代表因果，标识符的相关性也可能没有业务意义。

分析基于 pandas 实际列类型，不自动把文本类别转换成数值；清洗层会先处理可转换的数值文本。
输入要求列名为唯一字符串。分布和相关性排除 NA 与无穷，不对无数据作统计结论。

## 数据质量评分

`quality.quality_score(df)` 返回 `total_score`、四项 `scores`、`weights`、
`weight_reasons`、可核对计数 `details` 和 `has_data`，不修改输入。
各项与总分为 0–100 分，保留两位小数，总分为公开维度得分的加权和。

| 维度 | 权重 | 计算规则与权重理由 |
|---|---|---|
| 完整度 | 35% | 非 NA 单元格 / 全部单元格；缺失值直接减少可用信息，对后续分析影响最基础 |
| 唯一性 | 25% | 整行去重后行数 / 全部行数；重复观测会重复计权、扭曲统计 |
| 一致性 | 20% | 各列主导语义类型的非 NA 单元格数之和 / 全部非 NA 单元格；类型混杂影响计算，但无 schema 推断存在局限 |
| 有效性 | 20% | 有限且未被每列 1.5 × IQR 标记的数值 / 可解析数值；统计异常可能是真实观测，因此限制惩罚权重 |

这是未经业务数据校准的启发式默认权重，不代表普适标准。数值字符串和实数视为同类，
布尔值单独分类；日期对象归为日期类，日期字符串不会自动解析。
缺失只按 pandas NA 判断，不识别空白字符串或文本占位符。
不足 4 个有限数值的列不做 IQR 检查；有其他数据但无数值时，有效性记 100，表示未发现数值问题。
空表、没有列或全为 NA 时四项与总分均为 0，`has_data=False`，不会把无数据当作满分。
评分不验证业务真值或主键，填充后分数上升不意味着恢复了真实数据。

## 架构与开发

```text
src/
├── loader.py       # 数据读取层：CSV 编码处理与概览（保留原实现）
├── clean.py        # 数据处理层：去重、类型整理、缺失与异常处理（保留原实现）
├── quality.py      # 只读质量评分与权重解释
├── analyzer.py     # 只读探索性分析与结构化发现
├── qa.py           # 规则解析、固定 pandas 操作与会话上下文
├── report.py       # 将质量对比、自动发现和图表组织为 Markdown
├── main.py         # 可复用分析流水线与兼容的批处理 CLI
├── agent.py        # 会话管理、交互 CLI 与批量提问
└── make_sample.py  # 示例数据生成
tests/              # 原有清洗测试、新模块单测和 CLI/报告集成测试
```

在仓库根目录运行：

```bash
python -m pytest -q
python -m pytest tests/test_clean.py -v
python -m pytest tests/test_quality.py tests/test_analyzer.py tests/test_qa.py -v
```

原有 9 个清洗测试及断言保持不变；新增测试覆盖空表、全空、单列、混合类型、
分布/相关性、17 类问法、筛选和上下文、交互错误恢复及真实报告生成。
改动请通过独立分支和 PR 提交，PR 描述需给出行为变化及验证结果。
